# 统计范围规则构建器与工作台高级筛选

状态：已实现并通过回归测试
日期：2026-08-30

## 理解摘要

- 设置页中的统计工作区和命名项目要改成 Layout 风格的选项式规则卡片。
- 条件类型涵盖文件夹、标签、扩展名、文件名与 Properties；Properties 使用字段、运算符和值，不再要求 JSON。
- 每条可视化条件可选择与前一条的 `AND` / `OR` 关系；更复杂的嵌套、括号和 `NOT` 放在收起的表达式入口。
- 工作台默认仍跟随设置中选定的统计范围。
- 工作台新增默认收起的高级筛选；它应用后完全替代当前范围，而不是叠加。
- 临时筛选默认关闭工作台后清除；勾选“保留筛选”才将其存为本机偏好。
- 选择统计范围不能再触发整页设置重绘或滚动跳动。

## 约束与假设

- 规则只使用日历已有索引中的路径、标签与 Properties，不读取正文，也不依赖 Chinese Writing Layout 或 Dataview。
- 已保存的统计工作区和项目继续写入 `写作日历数据/projects/`，适合 Remotely Save 等仓库文件同步。
- 保留的工作台临时筛选是本机界面偏好，不会覆盖工作区、项目或云同步规则。
- 文件夹与已有标签优先提供下拉选项，同时保留手动输入；选项变化不触发额外全库扫描。
- 卡片排序属于规则语义的一部分，必须提供键盘可访问的上移、下移与删除操作。

## 决策记录

| 决策 | 备选 | 结论 |
| --- | --- | --- |
| 规则编辑器 | 两处独立表单 / 共享构建器 | 使用共享构建器，设置和工作台不会分叉。 |
| 规则表示 | 只存文本表达式 / 可视化条件树 + 表达式 | 存可视化条件树，并编译为现有独立表达式语义；表达式保留为高级入口。 |
| 工作台筛选 | 叠加当前范围 / 替代当前范围 | 临时筛选完全替代当前范围。 |
| 临时筛选保存 | 总是保留 / 默认清除、可勾选保留 | 默认清除；仅勾选后写入本机偏好。 |
| 页面刷新 | 整页重绘 / 局部更新并保留滚动 | 范围切换局部更新；工作台渲染保存并恢复滚动位置。 |

## 最终设计

### 条件树与兼容层

新增独立的、可序列化的条件树模型。节点包含连接词、条件类型和具体值；条件组用于括号。构建器将条件树编译为日历现有的 `folder()`、`tag()`、`extension()`、`filename()`、`property()` 表达式，并同用户填写的高级表达式一起计算。

已有 `includeFolders`、`includeTags`、Properties 等旧规则打开时被等价映射到条件树；保存后由条件树承载新语义，避免改变旧项目的统计范围。

### 设置编辑器

工作区和项目沿用同一个卡片列表。每张卡片具有条件类型下拉、按类型变化的控件、逻辑连接词、上移/下移/删除按钮和明确的无障碍标签。复杂原始表达式位于默认收起的详情区，普通用户无需接触语法。

### 工作台高级筛选

在写作统计页标题下放置可折叠面板。面板复用规则构建器，默认关闭。应用后以临时 `ProjectFilter` 运行统计，替代设置中的范围；清除后回到正常工作区/项目。保存复选框控制是否写入本机偏好。

### 滚动与性能

设置范围选择只更新关联文本，不调用整页 `display()`。工作台完整刷新前记录 `scrollTop`，完成后恢复；面板展开、收起和应用不会将用户带回页首。范围编辑只转换已有索引数据，不新增正文扫描。

## 验证策略

- 先为条件树的编译、AND/OR、Properties 与旧规则迁移写纯模型失败测试。
- 为工作台临时筛选“替代而非叠加”、默认清除和勾选保留写行为测试。
- 用界面源码/DOM 测试确认卡片控件、折叠面板和无障碍标签存在。
- 用回归测试确认范围选择不调用整页设置重绘，工作台刷新保留滚动位置。
- 最后运行完整测试、构建，并在测试库重载检查错误缓冲区。
